## ✨ Sections

- **Hero**: full-width banner with the restaurant's tagline
- **Today's Special**: featured dishes
- **Our Specialities**: sushi menu highlights
- **Dining Events**: private and fine-dining events
- **Our Story**: about the chefs and the restaurant
- **Footer**: contact details and links

A sticky navbar and a **mobile sidebar menu** (open / close in `script.js`) keep the page easy to use on phones.

## 🗂️ Structure

```
index.html   page markup
index.css    styles and responsive layout
script.js    mobile sidebar menu
assets/      images (dishes, chefs, interior, logos)
```

## 🚀 Run it

No build step: open `index.html` in a browser, or serve the folder with any static server
(for example the VS Code *Live Server* extension).
